# PDF Password Cracking Using John the Ripper

## Project Overview
As part of Week 3 of my Cybersecurity Internship at Networkwalks, I successfully performed PDF password cracking using John the Ripper in a controlled Kali Linux environment.

I extracted the password hash from a password-protected PDF file using pdf2john and used John the Ripper with a wordlist-based dictionary attack to successfully crack the PDF password.

## Tools & Technologies
- Kali Linux
- John the Ripper
- pdf2john
- Wordlist (Dictionary Attack)

## Practical Implementation
- Worked with a password-protected PDF file in a controlled lab environment.
- Extracted the PDF password hash using pdf2john.
- Loaded the extracted hash into John the Ripper.
- Executed a dictionary-based password cracking attack using a wordlist.
- Successfully cracked the PDF password and verified access to the protected file.

## Key Learnings
- Practical understanding of PDF password protection.
- PDF hash extraction techniques.
- Hands-on experience with John the Ripper.
- Dictionary-based password cracking methodology.
- Importance of strong passwords and resistance to wordlist attacks.

## Outcome
Successfully cracked the password of the test PDF file using John the Ripper, gaining practical experience in password recovery techniques and password security assessment.
